# 🚬 Smoking Health Risk Analysis | Power BI Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard designed to analyze smoking patterns and their relationship with different health risk indicators.

The dashboard provides insights into smoking habits, demographics, cholesterol levels, alcohol consumption, and other health-related factors.

## 🎯 Objectives

- Analyze smoking status across different age groups.
- Compare smoking patterns between males and females.
- Analyze smoking duration and daily cigarette intake.
- Study cholesterol levels across age groups.
- Understand alcohol consumption patterns.
- Identify health-risk patterns among different age groups.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

## 📊 Dashboard Features

- Total Patients
- Smoking Status Analysis
- Smoking Status by Gender
- Cholesterol Level by Age Group
- Smoking Duration Analysis
- Daily Cigarette Intake
- Alcohol Consumption Analysis
- Age Group-wise Health Risk Analysis
- Interactive Filters and Visualizations

## 🔍 Key Insights

The dashboard helps identify patterns between smoking behavior and various health-related indicators. It allows users to explore the data interactively using filters and visualizations.
